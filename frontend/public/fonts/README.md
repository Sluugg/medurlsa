# VCR OSD Mono Font

Place the following files in this directory:

- `VCROSDMono.woff2`
- `VCROSDMono.ttf`

The font is freely available from:
- https://www.dafont.com/vcr-osd-mono.font

After placing the files here, rebuild the frontend (`npm run build`).
If the files are absent, the title banner falls back to a system monospace font silently.
